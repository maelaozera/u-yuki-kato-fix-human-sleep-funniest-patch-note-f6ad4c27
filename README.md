A make.fun bounty entry: a tiny Node 22 / TypeScript program that writes a
single line of patch notes announcing that human sleep has been fixed.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the patch note to `out/entry.txt` — deterministically, with no
network access and no randomness.
